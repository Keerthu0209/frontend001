# Captain Cosmo's Space Academy

A fun HTML + CSS practice page built to learn semantic HTML elements, 
forms, tables, and CSS styling.

## Features
- Responsive layout with gradient backgrounds
- Navigation with anchor links
- Table for planet danger ratings
- Sign-up form with various input types

## Tech Used
- HTML5
- CSS3 (Flexbox, gradients, custom styling)
